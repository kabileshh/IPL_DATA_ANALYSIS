# IPL Data Analysis 

## Project Objective

This project analyzes IPL ball-by-ball match data from 2020 to 2024 to identify meaningful trends and performance patterns in T20 cricket.

The analysis focuses on:

* Toss impact on match outcomes
* Phase-wise scoring analysis
* Top-performing batters and bowlers
* Match-winning strategies and insights

---

## Tools Used

* Python
* Pandas
* Matplotlib
* Julius AI

---

## Dataset

The dataset consists of IPL ball-by-ball JSON match files converted into structured CSV format using Python-based preprocessing techniques.

---

## Data Preprocessing

The raw IPL JSON files were cleaned and transformed into a structured analytical dataset.

Preprocessing steps included:

* Flattening nested JSON structures
* Handling missing values
* Standardizing team names
* Converting data types
* Creating innings phase categories
* Engineering useful analytical columns

---

## Analysis Performed

1. Toss impact analysis
2. Match phase analysis
3. Top batter analysis
4. Top bowler analysis
5. Match-winning pattern analysis

---

## Key Findings

* Toss winners won only slightly more matches than toss losers
* Middle overs showed the strongest connection to winning matches
* Wicket preservation significantly influenced match success
* Winning teams maintained stronger scoring consistency across innings phases

## Surprising Insight

Despite common assumptions about toss advantage in T20 cricket, the analysis revealed that middle-over scoring had a much stronger connection to match victories than toss outcomes.
