# IPL Data Analysis (2020–2024)

## Project Objective

This project analyzes IPL ball-by-ball match data from 2020 to 2024 to identify meaningful trends and performance patterns in T20 cricket.

The analysis focuses on:

* Toss impact on match outcomes
* Phase-wise scoring analysis
* Top-performing batters and bowlers
* Match-winning strategies and insights

---

## Tools Used

* Python
* Pandas
* Matplotlib
* Julius AI

---

## Dataset

The dataset consists of IPL ball-by-ball JSON match files converted into structured CSV format using Python.

---

## Analysis Performed

1. Toss impact analysis
2. Match phase analysis
3. Top player analysis
4. Data preprocessing and cleaning
5. Insight generation from IPL match data

---

## Key Findings

* Toss advantage was smaller than commonly expected
* Middle overs showed the strongest connection to match victories
* Wicket preservation strongly influenced winning probability
* Consistent scoring across innings phases mattered more than late acceleration alone

---

## Project Files

* `IPL_ANALYSIS.pdf` → Final report
* `IPL_ANALYSIS.py` → Complete Python analysis
* `charts` → Visualization images

---
